- Ressources

Règles :

- toutes les vues utilisent une largeur maximale commune de 1180 px ;
- les anciennes largeurs spécifiques sont neutralisées ;
- responsive cohérent à 1100 px et 760 px ;
- aucune logique métier modifiée.
