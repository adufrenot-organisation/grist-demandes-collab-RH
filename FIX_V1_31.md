# V1.31 — catalogue complet de libellés visible

La V1.30 ne déclarait qu'une partie des textes.
V1.31 étend PARAM_LIBELLES aux textes visibles des écrans, notamment :
- SUIVI
- Historique et état de traitement.
- en-têtes RÉFÉRENCE / TYPE / PÉRIODE / MOTIF / STATUT / ACTIONS
- Aucune demande.
- titres, menus, boutons, champs, statuts
- écrans Ressources, Motifs, ACL, Synchronisation et Libellés.

Après installation, ouvrir Administration > Libellés de l'application puis cliquer
« Compléter / vérifier la table » pour ajouter les nouvelles clés sans écraser les valeurs personnalisées.
