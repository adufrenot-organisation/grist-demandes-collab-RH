# FIX V1.94 — Créer une demande depuis le planning

## Fonctionnement
- interaction uniquement sur la ligne de l’utilisateur réellement connecté ;
- clic simple : sélection d’une journée ;
- Shift+clic : extension de la sélection à une plage ;
- les jours passés, week-ends, jours fériés, absences confirmées et absences prévisionnelles ne sont pas sélectionnables ;
- bouton **Créer une demande** : ouvre le formulaire Nouvelle demande avec dates préremplies ;
- aucun effet en mode **Voir comme** ;
- respect de la règle d’accès existante aux menus de demandes.
