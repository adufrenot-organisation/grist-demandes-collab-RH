# V1.63 — Sélection libre d’une période de 15 jours dans le planning

## Évolution

Dans **Planning présence**, ajout d’un champ calendrier **Début de période**.

- Toute date peut être choisie.
- La vue affiche cette date et les 14 jours suivants, soit 15 jours calendaires inclusifs.
- Le bouton **Aujourd’hui** repositionne la période sur la date courante.
- Les flèches précédent / suivant déplacent la fenêtre de 15 jours.
- Le champ calendrier reste synchronisé lorsque la période est déplacée avec les boutons.

Aucune modification du schéma Grist n’est nécessaire pour cette évolution.
