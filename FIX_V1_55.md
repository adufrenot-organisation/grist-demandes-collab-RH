# V1.55 — Filtre Ressource dans Autres demandes

- Ajout d’un filtre Ressource dans l’écran **Autres demandes**.
- Le filtre ne propose que les ressources effectivement reliées aux demandes visibles dans cet écran.
- Ajout de la colonne **Ressource** au tableau pour identifier clairement le demandeur.
- Le compteur indique le nombre de demandes correspondant au filtre courant.
- Aucun changement de droits : l’écran reste réservé aux profils déjà autorisés (Admin / Owner).
